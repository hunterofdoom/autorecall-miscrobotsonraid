# AutoRecall: Misc Robots on Raid

A RimWorld mod that automatically recalls your **Misc. Robots** to their recharging stations when a raid or combat event occurs, ensuring your expensive utility robots don't get destroyed on the battlefield.

## Features

- **Automatic Recall:** Detects hostile raids and triggers a "Recall" command to all active robots.
- **Combat Protection:** Minimizes the risk of robots being caught in crossfire or targeted by enemies.
- **Seamless Integration:** Works with the existing [Misc. Robots](https://steamcommunity.com/sharedfiles/filedetails/?id=724602224) and [Misc. Robots+ expansion](https://steamcommunity.com/sharedfiles/filedetails/?id=747645520).

## Installation

1. Download the latest release.
2. Extract the contents into your RimWorld `Mods` folder.
3. Enable **AutoRecall: Misc Robots on Raid** in the in-game mod menu.

## Requirements

- **RimWorld** (Version 1.6+)
- **Misc. Robots** (Core mod)
- **Harmony** (Library)

## Technical Details

This mod uses **Harmony** to patch the raid trigger logic in RimWorld, sending a signal to all robot recharging stations to initiate a recall if they are currently deployed.
